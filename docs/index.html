01SEMANTIC CODE SEARCH

Grep that reads for meaning, not spelling.

sgrep slices your repo into chunks and asks Jev one cheap typed question per chunk — “does this match?” — then ranks by calibrated confidence. No keywords. No vector index to keep in sync.

02THE PROBLEM

Search for "authentication". Now find verify_jwt().

The code that matters rarely spells out the concept you're looking for. Here's how three approaches handle one query.

grep

Literal keyword match.

  • ✗ Misses verify_jwt() — the word isn't there
  • ✗ Fires on comments that just mention the term
  • ~ Fast, but you read every false hit
vector index

Prebuilt embedding database.

  • ~ Must build & keep an index in sync
  • ~ Approximate nearest-neighbour recall
  • ✗ Goes stale as the code changes
sgrepmeaning

Jev decides, one chunk at a time.

  • ✓ Finds verify_jwt() by what it does
  • ✓ No index — every chunk judged live
  • ✓ Ranked by calibrated confidence

03WHY IT WORKS

Every chunk judged on its own merits.

Meaning, not keywords

A function scores high for a concept even when the words never appear — and a passing mention in a comment won't false-positive.

"authentication" → verify_jwt() AuthMiddleware

No index to maintain

No vector DB to build or keep in sync. The local pre-filter embeds on the fly — only when a repo is large.

Scatter-proof

A flow spread across files, dirs and services is still found — chunks are decided independently of where they live.

Cheap enough for CI

A Jev call is ~150 tokens, ~100 ms, and the output is free — scanning a whole repo costs pennies. Run it on every PR.

06INSTALL

Up and running in a minute.

Python 3.10+. The first run pulls a tiny (~7 MB) local embedding model for the pre-filter. 

# global, isolated command (recommended)
$ pipx install sgrep

# or into the current environment
$ pip install -e ".[all]"

# ask your codebase anything
$ sgrep scan "where are JWT tokens verified" ./src

# trace a flow — batch up to 3 queries, one startup
$ sgrep scan "how are requests authenticated" ./src \
    -q "service-to-service auth" --json
  • → No API key? Run with --mock for an offline stand-in for Jev.
  • → Providers. TypeSafe direct (default) or the Vercel AI Gateway — keys read from a gitignored .env.
  • → Going faster. sgrep serve keeps the model warm; add --daemon to any scan.
  • → Ignore rules. A .sgrepignore plus automatic skipping of build/vendor & minified files.
